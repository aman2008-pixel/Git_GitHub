# Simple Billing System (PS No. 34)

A console billing system for a small shop, written in Python 3.
The cashier adds products with quantities for a customer, and the program generates a bill with subtotal, GST and grand total. The final bill is saved to `bill.txt`.

**University:** Rungta International Skills University
**School:** School of Computer Science and Engineering
**Programme:** B.Tech Computer Science and Engineering

## Features

- Product catalogue stored in a dictionary (Rice Rs.50, Sugar Rs.40, Oil Rs.120)
- Bill items stored in a list
- Functions to add an item, view the bill and generate the final bill
- Subtotal, GST (5% of subtotal) and grand total calculation
- Validation of product name and quantity
- Neatly formatted bill, saved to `bill.txt`

## Concepts Used

Lists, Dictionaries, Functions, File Handling

## How to Run

Make sure Python 3 is installed, then run from the console:

```
python one.py
```

Menu options:

1. Add item
2. View bill
3. Generate bill
4. Exit
